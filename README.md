# Farflung

Farflung is a free daily geography puzzle I built. You get 5 clues, pick a country, and drop a pin on the map. Rarer answers score more, so a bold guess can pay off.

## How it works
- A new location puzzle every day.
- Clues get more specific as you go.
- Choose a country, then place your pin.

Play it here: https://farflunggame.fun/
