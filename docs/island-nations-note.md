# Farflung island nations note

Study pointer for [farflunggame.fun](https://farflunggame.fun/) based on [island nations](https://farflunggame.fun/topics/island-nations).

- Island nation ≠ automatically borderless.
- Shared-island examples on the topic page include Haiti/Dominican Republic, Ireland/UK, Brunei/Malaysia.
- Australia treated as continental in that list; overseas dependencies are not separate playable countries.

See also [how to play](https://farflunggame.fun/how-to-play).

Maintained by the farflunggame.fun developer (independent edition).
