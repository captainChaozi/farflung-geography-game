# Guides index

Short, practical guides that accompany the [Farflung daily geography game](https://farflunggame.fun/) (independent edition).

| Guide | Use it when |
|---|---|
| [Read geography clues](https://farflunggame.fun/guides/read-geography-clues) | You pick a country that almost fits |
| [Map location strategy](https://farflunggame.fun/guides/map-location-strategy) | You know the country but misplace the pin |
| [Review geography mistakes](https://farflunggame.fun/guides/review-geography-mistakes) | You keep missing the same kind of clue |
| [Find unexpected countries](https://farflunggame.fun/guides/find-unexpected-countries) | You only ever answer the obvious country |
| [A fair daily challenge](https://farflunggame.fun/guides/a-fair-daily-challenge) | You wonder how the daily is kept fair |
| [Independent vs original](https://farflunggame.fun/guides/farflung-independent-vs-original) | You want to know how this edition differs |

Study topics (borders, landlocked countries, island nations, largest by area, equator) live under [topics](https://farflunggame.fun/topics). Teachers can start from [for teachers](https://farflunggame.fun/for-teachers).

Modes: Daily (five clues, up to 500 km of game points), Unlimited (repeatable), Wander (untimed).
