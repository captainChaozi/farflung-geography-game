# Farflung: panels that pause the Classic clock

Site: https://farflunggame.fun/

In Classic timed rounds (60 seconds), opening an in-game menu or rules panel can pause the clock once a selection is saved. Switching browser tabs does not pause it. Confirm current behaviour in [how to play](https://farflunggame.fun/how-to-play).
