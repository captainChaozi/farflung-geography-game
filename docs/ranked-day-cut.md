# Farflung: ranked attempt and the UTC day cut

Site: https://farflunggame.fun/

Daily and weekly ranking rules use a UTC midnight reset and one ranked attempt per UTC date. Sign in before opening the first clue if ranked status matters; a guest Daily on the same day can block a later ranked run. Confirm on [leaderboards/rules](https://farflunggame.fun/leaderboards/rules).
