# Farflung Edition 1.0: what the first atlas includes

Summary of the [Farflung product updates page](https://farflunggame.fun/updates) for this independent edition (checked 2026-11-02). Play at [farflunggame.fun](https://farflunggame.fun/).

## Edition 1.0 · October 2026

| Area | What shipped |
|---|---|
| Daily | A five-round shared daily challenge |
| Unlimited | Timed expeditions you can replay |
| Wander | Untimed practice with a searchable country list |
| Trails | Themed sets of clues |
| Archive | Closed daily challenges with answers, rarity, explanations and sources |
| Scoring | Server-validated answers and fixed scoring snapshots |
| Boards | Daily boards and best-five weekly boards |
| Social | Private friend challenges and invitation-only leagues |
| Passport | Countries correctly identified and achievements earned |
| Presentation | Original illustrated landscapes, a keyboard-accessible vector atlas, optional procedural music, spoiler-free postcard sharing |

## Notes

- Service status, provider availability and content corrections are shown in the relevant game interface, not on the updates page.
- The updates page is a change record, not a claim that every external service is configured.
- Daily timing and controls: see the [help page](https://farflunggame.fun/help).
