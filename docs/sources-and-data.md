# Farflung: sources and data at a glance

Where each kind of information in [farflunggame.fun](https://farflunggame.fun/) comes from. Full attribution: [sources & credits](https://farflunggame.fun/sources).

| Layer | Source | Licence / note |
|---|---|---|
| Map geometry | Natural Earth via `world-atlas` | Natural Earth: public domain; world-atlas distribution: ISC |
| Country names, capitals, neighbours, areas | Pinned GeoNames snapshot | CC BY 4.0 |
| Learning groups, subregions, label coordinates | Natural Earth 5.1.2 conventions | — |
| Country catalogue (195) | UN member list + Holy See + State of Palestine | See [countries and territories rules](https://farflunggame.fun/rules/countries-and-territories) |
| Question references | Per-question references with retrieval dates and scope | Private current / future answer sets are not in the public download |
| Rarity | Editorial estimate, optionally reviewed with AI and blended with eligible historical results | **Not** a geographical fact |
| Artwork, stamps, pins, frames | Original assets for this edition | Decorative; never supplies outlines or factual labels |
| Music and sounds | Original procedural compositions | — |

## Notes

- A map boundary alone is not evidence for every geographical claim; read each question's scope.
- A result's method label and sample count show what contributed to its frozen rarity score.

## Corrections

Every result has a question report action. Include a specific source and explain the scope mismatch.
