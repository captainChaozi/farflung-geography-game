# Farflung: independent edition vs the original

[farflunggame.fun](https://farflunggame.fun/) is an independently developed Farflung-style geography game with its own questions, artwork and records. The original game is at farflung.game, operated by Farflung LLC. This page summarises the differences, based on the [comparison guide](https://farflunggame.fun/guides/farflung-independent-vs-original) (official rules as checked 22 October 2026). The two games do not share accounts, results or leaderboards.

## Same idea

Read five geography clues and pin one qualifying country for each. Several answers may fit, and less expected correct answers score more.

## Differences

| Task | Original Farflung | Independent edition |
|---|---|---|
| Daily | One shared five-prompt expedition; resets at local midnight per the official guide | Five prompts per UTC day; reset at 00:00 UTC |
| Keep playing | Repeatable one-prompt untimed practice | [Unlimited](https://farflunggame.fun/unlimited): repeatable five-prompt timed expeditions |
| No clock | One-prompt practice | Wander: five untimed prompts, country search, explanations |
| Friends | See the official game | Private link with the same five frozen questions; invitation-only leagues |
| Reviewing answers | Answer map, country facts, Logbook, blog | Camp shows your five decisions; [archive](https://farflunggame.fun/archive) publishes accepted countries, frozen rarity and sources after each Daily closes |

## Ranking rules in this edition

- One ranked attempt per UTC day; opening the casual Daily first uses up that day's ranked attempt.
- Only total kilometres decide position; equal totals tie.
- Kilometres are game points, not real distances.
- No live AI call grades a pin; correctness comes from a reviewed answer set.
